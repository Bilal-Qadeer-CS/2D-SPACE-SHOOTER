This is a classic 2D Space Shooter game developed as part of my semester project at Information Technology University (ITU). The project focuses on core game development principles, including player movement, enemy AI spawning, and physics-based collision detection.

I successfully migrated this project from an older Unity version to Unity 6 to utilize the latest performance optimizations and updated C# features.

Key Features:
Player Combat: Smooth movement with a projectile-based firing system.

Enemy AI: Dynamic spawning logic with increasing difficulty.

Version Upgrade: Fully optimized and tested on Unity 6.

Clean Code: Organized C# scripts for movement, shooting, and game management.

Technical Stack:
Engine: Unity 6

Language: C#

Graphics: 2D Sprites with optimized Physics 2D components.

How to Play:
Clone the repository.

Open the project in Unity Hub (Version 6 or later).

Press the Play button in the editor.

Use Arrow Keys/WASD to move and Space to shoot.
