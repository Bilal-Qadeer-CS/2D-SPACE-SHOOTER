# 🚀 2D Space Shooter Game

This is a classic 2D Space Shooter game developed as a core academic and practical project to demonstrate fundamental game development principles, software architecture, and physics-based mechanics. 

The project has been successfully migrated from an older Unity long-term support (LTS) version to **Unity 6** to leverage the latest performance optimizations, modern rendering capabilities, and updated C# features.



### 🌟 Key Features

* **Advanced Player Combat:** Engineered smooth, responsive player movement coupled with a dynamic, projectile-based firing system.
* **Intelligent Enemy AI:** Implemented custom procedural spawning logic with progressive difficulty scaling to enhance gameplay engagement.
* **Engine Upgrade & Optimization:** Fully adapted, refactored, and thoroughly tested within the Unity 6 ecosystem for optimal frame rates and stability.
* **Clean & Modular Architecture:** Adhered to strict object-oriented programming (OOP) principles with decoupled C# scripts handling movement, combat, physics, and global game management.



### 🛠️ Technical Stack

* **Game Engine:** Unity 6
* **Programming Language:** C#
* **Physics & Graphics:** 2D Sprites integrated with optimized Physics 2D components and rigidbodies for precision collision detection.



### 🎮 How to Play / Run

1. Clone this repository to your local machine.
2. Open the project folder inside **Unity Hub** (Unity 6 or later required).
3. Open the main game scene and press the **Play** button in the editor.
4. **Controls:** Use Arrow Keys / WASD to move and press Spacebar to shoot.
